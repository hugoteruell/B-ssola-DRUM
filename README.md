# Bússola DRUM

Blueprint de produto e implementação da **Bússola DRUM** — um agente de IA conversacional que comprime o Programa Carreira da DRUM (7 etapas, semanas) em uma conversa de ~15 minutos, entregando uma North Star + 2–3 apostas testáveis para 90 dias.
